# 第 1 关：找到入口（linux-foundations）

### 题意理解

工作区 `/workspace/` 下有 `cabinet`、`logs` 等目录和 `input.bin`，材料包括输入文件和密钥文本。处理程序是 `/workspace/exam`，**调用接口以程序自身的帮助信息为准**。

提交 `/workspace/flag`：普通文件、不超过 1 MiB，内容必须与"输入经对应密钥和 exam 处理"得到的结果**逐字节相同**。

### 我的思路

三条提示正好对应三个动作：

| 提示 | 对应动作 |
| --- | --- |
| 路径从哪里开始解析，取决于它是绝对路径还是相对路径 | 先 `pwd` 确认自己在哪。相对路径是相对**当前工作目录**解析的，不是相对程序所在目录 |
| 不熟悉程序接口时查阅帮助信息 | 先跑 `/workspace/exam --help`，看清参数和输入输出位置 |
| 区分"程序生成的结果"和"提交要求的文件" | exam 输出的文件名未必叫 `flag`，要用 `cp` 原样搬运，**不能拿编辑器打开**（会破坏二进制）|

### 实现要点

```bash
cd /workspace
pwd
ls -la
/workspace/exam --help          # 先看接口
find /workspace -type f         # 材料可能藏在子目录里
# 按 --help 给出的参数调用，例如：
/workspace/exam <输入文件> <密钥文件> <输出文件>
# 再把结果原样搬到提交路径
cp <exam的输出文件> /workspace/flag
```

做完自信拉满
