
**输入**（标准输入）：

- 第一行：整数 `n`（1 ≤ n ≤ 10000）
- 第二行：`n` 个整数，空格分隔，每个在 `[-1000, 1000]`

**输出**（标准输出，**恰好 4 行**，`=` 两边不要有空格）：

```
count=<n>
sum=<所有读数之和>
min=<最小读数>
max=<最大读数>
```

程序必须以**退出码 0** 结束。

**提交要求**：构建入口必须是**根目录下恰好一个** `main.c` 或 `main.cpp`。两个同时存在、或一个都没有，都会得到 `SOURCE_MISSING`。

## 我的思路

这题本身不难（就是一次遍历统计），它真正考的是**工程习惯**，所以我把思路分成两层：

**算法层面**

四个统计量（count / sum / min / max）全部可以在**一次遍历**中更新完：

| 统计量 | 更新方式 |
| --- | --- |
| `count` | 每成功读入一个就 +1 |
| `sum` | 每读入一个就累加 |
| `min` / `max` | 用**第一个读到的数**初始化，之后每次比较更新 |

时间 O(n)、空间 O(1)，n ≤ 10000 完全够用，`sum` 在 32 位 int 范围内，不需要 64 位。

## 实现要点

```bash
cd /workspace
cp c/main.c main.c        # 把 C 模板复制到根目录当入口
rm -f main.cpp            # 根目录只能留一个入口文件
gcc -std=c11 -Wall -Wextra -o main main.c
```

实现：

```c
#include <stdio.h>

int main(void)
{
    int n;
    int i;
    int count = 0;
    int sum = 0;
    int min = 0, max = 0;
    int have = 0;

    if (scanf("%d", &n) != 1) {
        return 1;
    }

    for (i = 0; i < n; ++i) {
        int v;
        if (scanf("%d", &v) != 1) {
            return 1;
        }

        /* 关键：min/max 用第一个读到的数初始化，不能用 0 */
        if (!have) {
            min = v;
            max = v;
            have = 1;
        } else {
            if (v < min) min = v;
            if (v > max) max = v;
        }

        sum += v;
        count += 1;
    }

    printf("count=%d\n", count);
    printf("sum=%d\n", sum);
    printf("min=%d\n", min);
    printf("max=%d\n", max);

    return 0;
}
```
1. **min/max 用第一个数初始化，不能用 0。**
   读数在 `[-1000, 1000]`，如果全为正数（例如 `3 4 5`），用 0 初始化的 `min` 会输出 `min=0` —— 一个根本没出现过的值。这是本题最经典的错。
   我用了 `have` 标志位而不是"用第一个数初始化再循环剩余"，这样 n=1 时也不用特判，代码只有一条路径。

2. **前缀是 `=` 不是 `:`。**
   `count=5` 而不是 `count: 5`，`=` 两边也没有空格。

3. **恰好 4 行，且每行都以 `\n` 结尾。**
   不能多一行空行，也不能少最后一个换行。用 `printf("...\n")` 就是最省心的写法。

## 遇到的坑

**1. `SOURCE_MISSING` —— 根目录同时存在两个入口文件。**
- 现象：工作区里 `main.cpp`（C++ 模板）和 `c/main.c`（C 模板）一开始都在。如果只是"把 `c/main.c` 复制成 `main.c`"却忘了删 `main.cpp`，根目录就有两个入口。
- 原因：判题要求**根目录恰好一个** `main.c` 或 `main.cpp`，多于一个无法确定用哪个。
- 解决：`rm -f main.cpp`，保证根目录只有一个。

**2. min 初始化为 0 导致全正数输入输出错误。**

- 现象：输入 `3 4 5` 时输出 `min=0`，而 0 从没出现过。
- 原因：`min` 的初始值必须是**数据里真实存在的值**，而 0 只是 int 的默认值。读数范围含负数，所以"用 0 当上界/下界"在两侧都不安全。
- 解决：用第一个读到的数初始化。
